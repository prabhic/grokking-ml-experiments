Tokenization · vocabulary · sequence length

The model never receives your sentence.

Before an LLM can calculate attention, text must become a sequence of tokens. A token may be a whole word, punctuation, a space pattern, or part of a word.

Words are not always tokens

Common words may fit one token. Rare or long words can split into pieces, such as un + happiness. The exact split depends on the tokenizer.

Token IDs are labels

An ID is an index into a vocabulary. ID 418 does not contain meaning by itself; the model uses it to look up a learned vector later.

Punctuation counts too

Commas, periods, question marks, and sometimes spaces become tokens. That is why token count is not the same as word count.

Context has a cost

text → tokens → IDs
more tokens → more context positions
token limit counts tokens, not words

Tokenization is the first place where a prompt becomes a finite sequence.

The words on this page

token
A vocabulary item sent to the model.

The integer index assigned to a token.
vocabulary
The tokenizer’s fixed list of token strings.
word piece
A token that represents part of a word.
