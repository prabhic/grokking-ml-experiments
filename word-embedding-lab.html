Word embeddings · vector geometry · semantic similarity

A word becomes numbers. Relationships become geometry.

Choose cat and dog. Each word looks up a pair of numbers. Draw those numbers as arrows, compare their directions, and you have a way to measure a relationship. Move one word with the sliders: the ranking changes because the arithmetic only sees its coordinates.

Read the playground

Each point is a word’s vector endpoint. The teal arrow is word A; the rose arrow is word B. Both start at zero. The right rail compares the pair and ranks every other word against A.

The four boxes under the map follow the same calculation: pick words, look up vectors, compare directions, rank neighbors.

One comparison at a time

Multiply matching coordinates and add to get a dot product. Divide by both lengths to compare direction independently of length.

A · B = A₁B₁ + A₂B₂
‖A‖ = √(A₁² + A₂²)
cosine = (A · B) / (‖A‖ × ‖B‖)

Same direction gives 1, perpendicular gives 0, opposite gives −1. A zero vector has no direction, so its cosine is undefined.

One table, two views

The word map and nearest-word list show the same embedding table. Moving a point changes its comparisons everywhere. Selecting a different word only changes which table entry you inspect.

This map shows the full two-dimensional toy space. A two-dimensional projection of real embeddings would generally distort angles; similarity should be computed using the full vectors.

What the top bar changes

Words selects the two entries to compare. Compare loads a word pair. Edit A changes the coordinates of the selected word A, including when it also appears as B. Reset vectors restores the entire original table and keeps your selection.

Our coordinates are hand-authored. Real embeddings are learned from data across many dimensions, whose individual axes usually have no simple human label. These sliders demonstrate a representation; they do not train one.

The words on this page

embedding
A numeric vector assigned to an item, so relationships can be computed.
dimension
One coordinate in that vector. This table has two per word.
similarity
A chosen comparison rule. Here, cosine measures agreement in direction, not factual truth or probability.
nearest neighbor
The other word with the highest cosine score for the query.
token vs word
LLMs usually look up tokens, including word pieces. Later layers produce representations that also depend on context.

Try this

  1. Compare cat + dog, then cat + car. Watch the angle and cosine change together.
  2. Select cat + car. Set cat to [0.16, 0.90]. Different words, identical vectors: cosine becomes 1.
  3. Set cat to [0.08, 0.45]. Its length halves, but its direction and cosine with car stay the same.
  4. Set cat to [−0.16, −0.90]. The arrows oppose each other and cosine becomes −1.
  5. Set both coordinates to zero. There is no direction to rank. Reset vectors to restore the teaching data.
