LLM first principles · Hallucination Playground

Hallucination makes one hidden mechanism visible.

Confidence is not the same as available evidence. This playground keeps the moving parts small so the calculation can be followed from input to output.

Read the playground

Move the control and watch the highlighted result change. The four stages describe the mechanism in the same order as the code.

What this isolates

Confidence is not the same as available evidence. The toy values are teaching data; real models use larger vectors, matrices, vocabularies, and datasets.

Why it matters

This mechanism is one link in the first-principles chain from text to tokens, vectors, attention, prediction, and learning.

Terms

input is what enters the operation. transform is the calculation. output is what the next mechanism receives.
