Attention · query · key · dot product

A token asks a question. Keys show what each token can offer.

Attention begins by comparing one query vector with several key vectors. The dot product is a simple compatibility score: aligned directions score higher.

Query and key are roles

The query represents what the current token is looking for. A key represents what another token offers for matching. They are both vectors, but their roles differ.

Dot product is the first score

score(q,k) = q · k
= q₁k₁ + q₂k₂

Positive aligned coordinates add to the score. Opposing coordinates subtract from it.

Attention chooses later

This playground only ranks raw scores. Softmax will turn all scores into competing weights in the next playground.

Not factual similarity

The score measures compatibility in this toy vector space. It is not a truth score or a probability.

Terms

query
The vector asking what to look at.
key
The vector used to match that request.
