Waves · smooth signals · sinusoidal position encoding

A wave is not water. It is a pattern of values.

In this context, “wave” means a smooth mathematical signal: as position increases, a channel’s value rises and falls according to sine or cosine.

Position is the input

Position 0, 1, 2, and so on are the horizontal locations. We sample the wave at one location to get one signal value.

Channels use different waves

One coordinate can change quickly; another can change slowly. Together, many frequencies create a distinctive pattern for each position.

Why this helps an LLM

The model receives a vector of these sampled values. Nearby positions have related patterns, while different positions have different combinations.

Formula

signal(position) = sin(2π × position / wavelength)
another channel = cos(2π × position / wavelength)

What “sinusoidal” means

It simply means the signal is made with sine and cosine functions. It is fixed by a formula rather than learned from a table.
