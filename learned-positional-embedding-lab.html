Learned position embeddings · lookup · addition

Position can be learned as a table row.

Instead of calculating a fixed sinusoidal signal, a model can store one learned vector for each position. Position 0 retrieves one row; position 1 retrieves another.

Two tables, one input

The token table provides the token vector. The position table provides the position vector. The transformer receives their element-wise sum.

Same token, new position

dog uses the same token row at positions 0 and 2, but the position row differs, so the combined vector differs.

Learned means trained

The position rows begin as parameters and are adjusted during training. They are not necessarily sine waves or human-readable labels.

Formula

input[position] = token_table[token] + position_table[position]

Terms

position table
A learned vector row for each allowed position.
maximum length
The number of positions the table supports.
lookup
Use the position index to retrieve its row.
