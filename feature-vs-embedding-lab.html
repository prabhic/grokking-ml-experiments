Representation · features · embedding dimensions

Same idea. Different kind of number.

A traditional feature vector stores named measurements. An embedding vector stores a learned location in a space. Both are lists of numbers, but the numbers play different roles.

Features have names

For a house, rooms, area, and age describe real measurements. Dimension 1 has a stable meaning: rooms.

Embedding dimensions have positions

For a word, D1, D2, D3, and D4 are coordinate positions. A single axis is usually not “animal-ness.” Meaning is distributed across the pattern.

Rotation changes labels, not relationships

Press Rotate axes. Coordinates change, but relative geometry stays the same. This is why one embedding dimension should not be given a fixed human meaning.

Useful vocabulary

feature vector → named measurements
embedding vector → learned coordinates
dimension → one coordinate position
vector → the complete list together

“Feature vector” is valid. “Embedding vector” is more precise when coordinates have no fixed meanings.

The words on this page

feature
An input measurement with an intended interpretation.
dimension
One coordinate position in a vector.
embedding
A learned representation whose geometry carries relationships.
rotation
A coordinate change that preserves distances and angles.

Try this

  1. Compare the house example: labels remain rooms, area, and age.
  2. Switch to Word and inspect D1–D4. No coordinate gets a tidy concept label.
  3. Press Rotate axes. Values change while the relationship score stays the same.
