Scalar index · vector representation · element-wise addition

An address becomes a signal the model can combine.

The position number is fixed. The conversion is the important step: turn that one number into a vector with the same width as the token vector, then add them.

Why not add 1?

A token vector has one value per coordinate. The scalar 1 has no matching coordinate structure. A position vector supplies one value for every token coordinate.

What is fixed?

Position 1 remains position 1. Only its representation is a vector. Different systems calculate that vector differently: a learned table, sine/cosine formula, or rotary transformation.

What does addition do?

token [0.8, 0.2]
position [0.0, 0.2]
input [0.8, 0.4]

The result keeps the same width, so later layers can process it normally.
