Position · sequence order · transformer input

The index is fixed. The vector signal can change.

Tokenization gives the model an ordered sequence of IDs. The index is already fixed for this sentence; the model still needs a vector representation of that index so it can distinguish “dog bites man” from “man bites dog.”

The index is already fixed

The token dog can occur at position 0, 1, or 20. Its token embedding can be the same row; the position index tells us where it is. A separate vector representation of that index is what changes the model input.

Why turn an index into a vector?

model input = token embedding + position encoding

The integer index is not added directly. It addresses or calculates a same-width vector, and that vector can then be added to the token vector. The result keeps the same width.

Order changes relationships

Reordering a sentence changes which position signal is added to each token. Later attention layers can use those changed vectors to learn order-sensitive patterns.

What can be learned?

The position number is not learned. The representation can be fixed (sinusoidal) or learned (a table row). The mechanism here is intentionally tiny and visible.
